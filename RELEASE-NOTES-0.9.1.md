# Reef UI 0.9.1

First public release of Reef UI, an unofficial navy and bronze interface mod for Sunkenland.

- Restyled main menu, character/world screens, settings, loading, pause, tutorials, tips, and confirmation dialogs.
- Warm hover and selection feedback, updated food/water icons, spaced vitals, and styled quest cards.
- Padded crafting ingredients and building cards grouped by function, shape, and material.
- Name-only profession, hobby, and starting-item choices, with the selected option's actual localized benefits on the right.
- Native controls, option order, eligibility rules, starting bonuses, and save behavior retained.
- Styling triggered by relevant UI events, without a recurring hierarchy scan or per-frame styling loop.

## Download and install

Download **Sunkenland.ReefUI-0.9.1.zip** from the assets below. GitHub's automatic source-code archives are for development and do not contain the installable plugin.

Install **BepInEx 5.4.23.6 for Windows x64 / Unity Mono** separately, set `HideManagerGameObject = true` under `[Chainloader]` in its configuration, then extract the mod ZIP into your Sunkenland folder while the game is closed. Start through Steam.

[Full installation, update, and removal guide](https://github.com/theoneonlykid69/sunkenland-reef-ui/blob/v0.9.1/INSTALL.md) · [Screenshots and compatibility](https://github.com/theoneonlykid69/sunkenland-reef-ui/tree/v0.9.1#screenshots)

Development baseline: **Sunkenland Beta 0.9.35**, Windows x64, Unity Mono 2021.3.45f2. The author checked the finished selection interface in-game. Release compilation and static checks passed; those checks are not an FPS benchmark.

The ZIP contains only the mod, two authored textures, artwork provenance, and installation/license notices. No game assemblies, extracted game assets, or mod-loader binaries are included.
