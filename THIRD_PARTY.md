# Dependencies and game content

Reef UI depends on components supplied by your own installation. Their binaries are not redistributed here.

| Component | Source |
| --- | --- |
| Sunkenland and its Unity managed assemblies | Your installed copy of Sunkenland |
| BepInEx 5 | [Official BepInEx releases](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.6) |
| HarmonyX (`0Harmony.dll`) | Included with BepInEx; [HarmonyX project](https://github.com/BepInEx/HarmonyX) |
| Mono.Cecil, used by the development verifier | Included with BepInEx; [Mono.Cecil project](https://github.com/jbevain/cecil) |
| TextMesh Pro | Your installed game's managed assemblies |

Game screenshots are documentation of the mod in use. No game art is extracted into the runtime mod package. The two runtime panel textures are mod-authored AI-generated artwork; see [artwork provenance](Assets/ARTWORK.md).
